# Contributing

Report the instrument label, board revision if known, host environment, commands, expected results, and observed results. Include failed attempts when they help someone reproduce the investigation. Label observations, third-party claims, and hypotheses, and link to primary sources where possible.

Review logs, images, and terminal output for serial numbers, Bluetooth addresses, usernames, tokens, and identifying host data before sharing. Keep vendor firmware dumps privately. Factory firmware preservation and recovery take priority over device modification.
