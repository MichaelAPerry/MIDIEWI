# Processor candidate database

This ranking applies to U6 on the filmed Vangoa board. Rank indicates priority for a **pin-map comparison**, rather than the probability of finding the part. No listed IC has a positive marking or verified net match. Clock predictions are conditional on establishing the U6-local 12 MHz resonator's two active pin connections. USB pins matter only if USB1 is traced to U6. [Topology notebook](../experiments/2026-11-26-mainboard-topology.md)

An unidentified integrated audio MCU and a split USB-controller plus synth architecture both remain viable. The largest evidence gaps are the actual USB D+/D− destinations, both oscillator endpoints and a traced signal source for the audio output. A readable chip marking or an independently documented board net outranks package similarity.
